## 完整工作流程

### 阶段1：项目初始化

**Step 1.1 — 询问用户基本信息**

当用户说"写小说"、"开始写"、"想写小说"时，先问4个问题：

```
1. 题材/类型？
   （从35种类型列表选，或描述想写的方向）

2. 世界观风格？
   （西幻/东方/末世/都市/未来科幻等）

3. 主角设定？
   （穿越/本土/重生/普通人/特殊能力等）

4. 篇幅预期？
   （短篇5千-1万 / 中篇1-3万 / 长篇3万以上）
```

**Step 1.2 — 生成故事种子**

如果用户只给了方向没有具体想法，用以下模板主动生成3个故事种子供选择：

```
【种子A】类型+核心设定+核心悬念
【种子B】类型+不同核心设定+不同悬念
【种子C】类型+混合元素+独特设定
```

**Step 1.3 — 创建项目**

用户确认故事种子后，创建项目结构：

```bash
mkdir -p ~/novel-project/01_档案
mkdir -p ~/novel-project/02_正文
mkdir -p ~/novel-project/03_工具
```

---

### 阶段2：生成大纲

**命令：**
```bash
cd ~/novel-project
python 03_工具/write_chapter.py outline <类型> "<故事种子>" [章节数]
```

**流程：**
1. 执行脚本，生成章节大纲
2. 大纲包含：每章章节名、核心事件（2-3句）、结尾钩子
3. 发给用户确认
4. 用户确认后，手动保存到 `~/novel-project/01_档案/剧情大纲.md`

**章节数参考：**
- 短篇（5千-1万字）：6-10章，每章800-1500字
- 中篇（1-3万字）：12-20章，每章1500-2500字
- 长篇（3万+字）：20-40章，每章2000-4000字

---

### 阶段3：逐章撰写

**命令：**
```bash
cd ~/novel-project
python 03_工具/write_chapter.py chapter <类型> <章号> <章节主题>
```

**流程（每章）：**
1. 脚本自动读取 `01_档案/章节日志.md` 获取前章摘要
2. 调用 DeepSeek 生成章节正文
3. 脚本输出章节内容到 stdout
4. **手动保存**到 `02_正文/第XXX章_章节名.md`
5. **手动更新** `01_档案/章节日志.md`（记录本章关键事件）
6. 发送飞书给用户审阅

**注意：** 脚本不会自动保存，需手动保存章节文件。

---

### 阶段4：章节目志更新

每章写完后，更新章节日志格式：

```markdown
## 第X章 章节名 (YYYY-MM-DD)
- **人物**：角色名/状态变化
- **地点**：章节发生地点
- **核心事件**：本章主要剧情
- **关键道具/信息**：获得的物品、听到的关键信息
- **悬念/钩子**：留给下一章的悬念
```

## 飞书发送规范

- 每章写完后，发送全文到飞书
- 标题格式：`《书名》第X章 章名`
- 正文直接发送 markdown
- 发送后等待用户反馈，再写下一章

## 常见问题处理

**Q: 用户没说清楚想要什么类型？**
A: 提供3个不同类型的选项，让用户选择或描述想法

**Q: 脚本生成的大纲不符合预期？**
A: 重新生成，或让用户修改故事种子后重新生成

**Q: 章节太长被截断？**
A: 分两次生成，标记"上/下"，分别保存

**Q: 用户想调整已写章节的内容？**
A: 重新调用脚本生成，或基于用户反馈手动修改
