# 经验类信息稿公文格式参数（速查）

> 来源：五莲县统战部信息报送格式要求.txt + tongzhan-info-workflow 实战验证

## 经验类（400-500字）

| 项目 | 参数 |
|------|------|
| 总字数 | 400-500字 |
| 标题字体 | 黑体三号（16pt），居中，标题前空两格 |
| 正文字体 | 仿宋_GB2312 三号（16pt） |
| 英文/数字字体 | Times New Roman 三号（16pt） |
| 段落间距 | 28 磅（固定值） |
| 页边距 | 上3.5cm、下3.2cm、左右2.7cm |
| 首行缩进 | 2字符 |
| 对齐方式 | 两端对齐 |
| 小标题格式 | 与正文一致（仿宋三号），加粗 |

## 问题类（2-3页）

| 项目 | 参数 |
|------|------|
| 总字数 | 2-3页篇幅 |
| 标题字体 | 黑体三号（16pt），居中 |
| 正文字体 | 仿宋_GB2312 三号（16pt） |
| 英文/数字字体 | Times New Roman 三号（16pt） |
| 段落间距 | 28 磅（固定值） |
| 页边距 | 上3.5cm、下3.2cm、左右2.7cm |
| 首行缩进 | 2字符 |
| 对齐方式 | 两端对齐 |
| 结构 | 背景 / 原因 / 建议（背景可省略） |

## 快速生成代码模板

```python
import sys
sys.path.insert(0, '/home/lxgxdx/.hermes/skills/ppt-work/document-work/document-editor')
from editor import WordDocumentEditor

editor = WordDocumentEditor()
editor.set_page_setup(top=3.5, bottom=3.2, left=2.7, right=2.7)

# 标题
editor.add_paragraph('标题', font_name='黑体', font_size=16, bold=True, align='center')

# 正文
for para in ['第1段...', '第2段...']:
    editor.add_paragraph(para, font_name='仿宋_GB2312', font_size=16,
                         bold=False, align='justify', first_line_indent=True, line_spacing=28)

editor.save('/output.docx')
```
