# 未生效新法 / 软法 的处理方法

> 适用：法律刚通过尚未生效 / 法律性质为"促进法"类软法 / 法律条文中缺乏刚性罚则
> 范例：`~/wiki/entities/policy-minzu-tuanjie-promotion-law.md`（P17，2026-06-05 建设）

---

## 1. 与传统"已生效法"页面的关键差异

| 维度 | 已生效法 | 未生效法 / 软法 |
|------|---------|----------------|
| 真实执法案例 | ✅ 可找到 | ❌ 不存在（无人被追责） |
| 案例章节 | "典型执法案例" | "准备实施阶段信号" |
| 问题标注重点 | 条款执行偏差 | 立法技术 / 实施细则同步 / 准备充分性 |
| 评估对象 | 基层执法部门 | 立法者 + 实施准备者 |
| 软法判定 | 不适用 | 必填章节 |

## 2. "案例"四类替代来源（按可靠性排序）

### 2.1 主管机关署名文章（最可靠）

**特点**：法律发布后 1-3 个月内，主管机关领导/部门在党报党刊发表署名文章

**挖掘信号词**：
- "**从 X 为主向 Y 为主转变**" → 暗示原 X 模式有问题
- "**全面有效实施**" → 暗示此前部分实施不全面
- "**夯实 X 根基**" → 暗示基础不牢
- "**补齐 X 短板**" → 直接承认短板

**实例**：
- 2026-05-13 国家民委署名文章（neac.gov.cn 时政要闻）
- 关键句"从行政推动为主向法治保障为主转变" → 即印证长期"行政化、运动化"问题

**获取路径**：
1. 主管机关官网（如 neac.gov.cn） → 频道"时政要闻"/"媒体关注"/"署名文章"
2. 党报党刊《求是》《学习时报》→ 党建网（12371.cn）

### 2.2 党校/学习时报释义文章

**特点**：中央党校（国家行政学院）专家在《学习时报》发文解读立法意义

**挖掘要点**：
- 是否直接承认"此前 X 不够"？
- 解读的角度是"立法必要性"还是"实施挑战"？
- **警惕纯宣传文**：通篇说立法多重要，未提实施挑战——价值低

**实例**：
- 2026-04-14 中央党校《学习时报》"制定民族团结进步促进法 推动宪法有关规定全面有效实施"（ccps.gov.cn）

### 2.3 实施前研究论坛

**特点**：生效前 1-2 个月举办的学术/实务论坛，主题是"如何学习贯彻"

**挖掘信号词**：
- 论坛主题 = "原则如何转化为可操作制度" → 直接印证"原则性强、操作性弱"
- 讨论焦点 = "基层能力建设" → 反映基层承接能力不足
- 关注度 = "全国 X 部门联合举办" → 反映重视程度 / 协调困难

**实例**：
- 2026-05-23 第五届铸牢中华民族共同体意识研究论坛（成都）
- 距生效日 38 天举办，主题"学习贯彻本法"

### 2.4 实施前部署会议

**特点**：生效前最后阶段召开的全国性部署会议

**挖掘信号**：
- 距生效日 < 1 个月召开 → 反映**准备仓促**
- 提及"实施细则"但未给出时间表 → **反映配套滞后**
- "督促各地各部门"→ **反映地方落地参差不齐**

**实例**：
- 2026-06 初全国民委主任会议
- 距生效日 < 30 天，无省级实施办法

## 3. 软法性质自评清单

填入 policy-xxx.md 页面 3.1 章节前的"软法判定"小节：

```markdown
**软法性质自评**：
- 全文条款数：约 N 条
- 倡导性条款占比：约 X%（"促进""鼓励""深入""加强"）
- 义务性条款占比：约 Y%（"应当""必须"）
- 法律责任章节：第 X 章（具体罚则 / 仅原则表述 / 完全缺失）
- 监督机制：依赖党政考核 / 独立监督机构 / 无明确机制
- 综合定性：硬法 / 软硬混合 / 软法
```

## 4. 写作模板（章节顺序）

```markdown
# 法律名

## 立法背景
- 立法史节点（首部"促进法"/填补 X 空白/对 X 的具体化）
- 立法历程时间线

## 核心规定摘要
- 总则部分（核心条款）
- 主要制度设计（4-5 个分领域）
- **重要说明**：刚通过尚未生效，部分条款需待官方释义补充

## 执行层面问题标注 ⚠️
### 软法性质自评（如适用）
### 3.1 模糊地带
### 3.2 执行空白
### 3.3 多部门协调
### 3.4 监督缺失
### 3.5 基层执行难点（预判）

## 典型新闻案例（近期·生效前）
> ⚠️ 以下案例为"准备实施阶段制度问题信号"，**非执法案例**
### 案例 1：主管机关署名文章
- 来源 + 时间 + 核心观点 + 反映的制度问题
### 案例 2：党校释义文章
### 案例 3：研究论坛
### 案例 4：部署会议

## 信息稿选题角度提示（5-8 条）

## 与本县（五莲县）工作相关（如适用）
- 散居地区特殊性
- 工作建议（3-4 条）
- 可用信息稿角度（3 个）

## 相关政策链接（[[policy-xxx]] 双向链接）
```

## 5. 真实案例：P17《民族团结进步促进法》

- **建设日期**：2026-06-05
- **法律状态**：2026-03-12 通过，2026-07-01 生效
- **软法判定**：硬法（国家法律）+ 软法内容（倡导性条款偏多）
- **问题标注**：4 类（模糊地带/执行空白/多部门协调/监督缺失）
- **收录案例**：4 条（均为"准备实施阶段信号"）
- **特殊处理**：
  - 新增"软法性质自评"小节
  - 案例章节标题改为"典型新闻案例（近期·2026-03以来）"而非"执法案例"
  - 新增"与本县工作相关"小节（五莲为散居少数民族地区）
  - 标注"待补充"——生效后补逐条对照

## 6. 反模式（不要做）

- ❌ **编造执法案例**——新法没人被罚，硬凑将污染知识库
- ❌ **照搬法律新闻稿**——价值低，缺乏分析
- ❌ **把"应当"条款当"必须"条款**——软法特点就是义务条款偏少
- ❌ **省略软法判定**——读者无法判断可执行性
- ❌ **未与本县工作挂钩**——失去县级统战工作场景的针对性
