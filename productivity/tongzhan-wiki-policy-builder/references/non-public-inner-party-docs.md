# 党内规范性文件原文不公开 — 处理手册

> 适用场景：中央组织部、中央统战部、中办、国办等联合印发的**党内规范性文件**——发布层级低于党内法规，原文不在中央统战部官网公开，仅"内部掌握、适当公开"。

## 一、文件类型判定

| 维度 | 党内法规 | 党内规范性文件 | 部门规章 |
|------|----------|--------------|----------|
| 例 | P13《中国共产党统一战线工作条例》 | P12《关于进一步规范党外代表人士双重管理工作的意见》 | P15《中国光彩事业促进会章程》 |
| 发布层级 | 中央（中央办公厅/中共中央） | 中央部门联合印发（中央组织部+中央统战部等） | 单一部门/社团 |
| 公开程度 | 通常全文公开 | 通常**不公开原文** | 全文公开 |
| 检索渠道 | 共产党员网党内法规库、人民日报、新华社 | **公开渠道仅见引用、讲话、解读** | 部门官网 |
| 知识库处理 | 全文照录 + 标注执行问题 | "2026公开讲话反推" + 标注执行问题 | 全文照录 + 标注执行问题 |

**判定方法**：
```bash
# 1. 在中央统战部官网全文检索文件名
curl -sL -A "Mozilla/5.0" "https://www.zytzb.gov.cn/zytzb/search.html?wd=文件名关键词"
# 2. 共产党员网党内法规库检索
# 3. 百度/Bing 检索 "+ 全文" 看是否有官网转载
```

**判定信号**（满足任一即可能为"原文不公开"）：
- 搜索"文件名 + 全文"无任何官网 PDF/HTML 结果
- 仅见学者论文、地方汇报中**间接引用**
- 中央领导讲话中**笼统提及**而不引用条款
- 提纲对它的描述是"中办印发"而非"中共中央印发"

## 二、"2026 公开讲话反推"路径（核心方法论）

当原文不可得时，**反向论证**比"基于领域知识猜测"更可靠：

### 2.1 三类反推证据

| 证据类型 | 来源 | 权重 |
|----------|------|------|
| **中央领导公开讲话** | 李干杰、王沪宁等中央领导在公开会议上的讲话（如 2026-05-20 李干杰在党外代表人士队伍建设研讨会上的讲话） | 高（第一手） |
| **配套会议安排** | 中央统战部"党外人士形势政策报告会"等定期会议（2024-09 起每年 3-4 期） | 中（机制存在性证据） |
| **P13 母法依据** | P13《中国共产党统一战线工作条例》第三章第十二条 | 中（法理框架） |

### 2.2 5 类"信号性引文"模式

中央领导讲话中**特定用语**本身就是制度漏洞证据：

| 引文模式 | 反映的制度问题 | 案例 |
|----------|--------------|------|
| "强化管理监督的针对性实效性" | 承认监督针对性不强、实效性不足 | P12 案例 1（李干杰 2026-05-20） |
| "近期印发有关文件" | 新文件存在但未公开 | P12 案例 1 |
| "推动党的统一战线工作制度体系进一步完善" | 承认现行制度体系不完善 | P12 案例 1 |
| "高质量完成各项任务" | 强调质量、隐含"低质量完成"问题 | 多种场景 |
| "再上新台阶" | 承认当前水平不够 | 多种场景 |

### 2.3 案例应包含字段

```markdown
### 案例X：[讲话/会议全称]（YYYY-MM-DD）⚠️ 关键制度信号
- **来源**：中央统战部官网 https://www.zytzb.gov.cn/zytzb/YYYY-MM/DD/article_*.shtml
- **主持人**：[姓名+职务]
- **出席**：[名单]
- **关键摘录**：
  > "[讲话原文引用，标注⚠️信号性用语]"
- **反映的制度漏洞**：
  - ① 模糊地带：[具体表现]
  - ② 执行空白：[具体表现]
  ...
```

## 三、页面顶部明示 + raw 摘要说明

### 3.1 页面顶部 frontmatter 后立即声明

```markdown
> **公开程度**：原文未在政府官网公开全文，属"内部掌握、适当公开"层级
```

### 3.2 条款摘录前加 ⚠️ 声明

```markdown
> ⚠️ **声明**：本《意见》原文未公开，以下条款基于 P13《统一战线工作条例》、P14 山东省实施细则、中央组织部公开发布的干部工作一般原则、以及 2026-05-20 李干杰讲话反推。涉及具体条款号的内容以"推断"标识。
```

### 3.3 raw 摘要必须包含"原文获取难度评估"小节

```markdown
## 五、文件原文获取难度评估
- **公开渠道**：未在中央统战部官网首页检索到该《意见》原文链接
- **推断来源**：中央组织部、中央统战部联合印发属中层级党内文件
- **建议获取路径**（cron run 失败时）：访问共产党员网 https://www.12371.cn/ 内"党内法规库" → 检索关键词
- **备用获取**：中央组织部官网、中央统战部"理论时评"栏目深度文章
```

## 四、与其他模式的区别

| 模式 | 适用场景 | 案例替代来源 | 章节结构特殊点 |
|------|----------|------------|---------------|
| 正常政策页 | 原文公开的法律/规章 | 执法案例、行政处罚、媒体报道 | 标准 9 章节 |
| 未生效新法/软法 | 即将生效或倡导性 | 主管机关署名文章、释义文章、部署会议 | "准备实施阶段信号"小节 |
| **党内规范性文件（本文）** | 原文不公开但已生效 | 中央领导公开讲话、配套会议安排、母法条款 | 顶部"公开程度"声明 + 条款摘录前 ⚠️ 声明 + raw 含"原文获取难度评估" |
| 索引页 | 全文在另一个 wiki | 真实执法案例 + 制度逻辑串联 | "软法-硬法"分析框架 |

## 五、完整建设流程（替换默认 5 步）

| 步骤 | 正常 | 党内规范性文件 |
|------|------|--------------|
| 步骤 1 选政策 | 标准流程 | 同左 |
| 步骤 2 抓取原文 | 下载 PDF/HTML | **跳过**——直接声明"原文不可得" |
| 步骤 2.5 反推原文 | — | **新增**：从中央领导讲话、母法、配套会议反推条款 |
| 步骤 3 找案例 | 执法案例 | 中央领导讲话 + 配套会议 |
| 步骤 4 写页面 | 标准模板 | + 顶部"公开程度"声明 + 条款摘录前 ⚠️ + 章节"原文获取难度评估" |
| 步骤 5 更新索引 | 标准 | 同左 |

## 六、真实案例：P12《关于进一步规范党外代表人士双重管理工作的意见》

### 6.1 深化前状态

- 58 行 / 2.1KB / 1 类问题标注 / 0 条真实案例
- "原文未公开"导致 5 类问题标注无法完整做
- 仅含制度框架描述

### 6.2 深化后状态（2026-06-11）

- 282 行 / 19KB / 9 章节 / 5 类问题全覆盖 / 2 条 2026 年真实案例 + 3 档五莲县级工作建议 + 7 条信息稿选题
- 案例 1：2026-05-20 李干杰出席党外代表人士队伍建设研讨会
- 案例 2：2026-04-22 中央统战部党外人士形势政策报告会
- 关键发现：李干杰讲话中"近期中共中央印发有关文件"是判断 P12《意见》是否被替代或扩充的关键时间锚点

### 6.3 反思

**为何 P12 能被深化到 19KB**（对比 P15 深化后 8.8KB）：
- P12 是 5 类问题**最易挖**的政策——党外干部管理是组织部门 + 统战部门 + 政府 + 8 个民主党派 + 无党派人士**多方协调的活标本**
- P15（光彩事业章程）相对封闭——章程本身条款就是核心
- **结论**：深化"协调链条长"的政策，深度天花板远高于"实体性条款"的政策
