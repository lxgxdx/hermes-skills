# 五莲统战 Wiki 知识库 — 参考资料

## 1. 5 类"执行层面问题"框架（核心方法论）

> 这是本知识库的差异化价值——政策原文人人能查，但"执行层面问题"标注需要分析者下功夫。每新建一个政策页面，必须按这 5 类组织标注。

### ① 模糊地带（Legislative Ambiguity）
- 关注：立法语言本身用词的模糊
- 常见关键词：**"原则上""视情况""依法""国家需要""符合规定""妥善处理""有关部门"**
- 提问：基层干部/台胞/宗教界会怎么理解？"合理"的范围谁来界定？
- 案例：P05 第十二条"享受优惠待遇"——"有关规定"散见于数十个文件中，基层难以全面掌握

### ② 执行空白（Implementation Gap）
- 关注：法律有要求但缺乏配套细则
- 常见模式："应当/可以/鼓励做 X" → "具体办法由 XX 制定" → 但 X 一直没有出台
- 提问：哪些环节从中央政策到基层操作出现"最后一公里"断点？
- 案例：P05 第十一条"委托亲友作为投资代理人"——无代理行为规范细则

### ③ 多部门协调（Inter-Agency Coordination）
- 关注：涉及多个部门但职责边界不清
- 识别信号："应当与 XX 部门协调""由 XX 部门会同 YY 部门"——是**协调**还是**职责转移**？
- 关键节点：是否有**部际协调机制**？什么时候建立的？
- 案例：P05 涉及国台办、商务部、发改委、市监总局、外汇局、公安部、自然资源部 10+ 部门
- **典型数据**：部际协调机制通常在问题暴露 5-10 年后才会建立（参考 "31条"2018 → "部际协调机制"2024）

### ④ 监督追责（Accountability）
- 关注：违反条款如何处理？由谁监督？是否有具体罚则？
- **黄金标准问题**：翻遍全文，能找到 X 条以上的"法律责任"条款吗？具体的处罚措施是什么？
- 监督机构是否有独立性？（如宗教工作 + 台办都兼具"推动政策"和"监督执行"双重职能——存在角色冲突）
- 案例：P05 第十八条仅"违反本法规定的处理"原则表述，无具体罚则

### ⑤ 历史遗留（Historical Legacy）
- 关注：法律颁布后时代变化导致的脱节
- 典型问题：
  - 立法范畴滞后（"投资保护" → 现在需要"通桥通水、文化影视"）
  - 后续法律的对接（如 P05 母法未对接 2020 年《外商投资法》）
  - 国际/区域协定对接（如 WTO/RCEP 中的"原产地"问题）
  - 突发事件应对缺位（如新冠疫情期间台胞跨境人员往来问题）
- 案例：P05 "投资保护"范畴被 2018-2026 年四份政策性补强文件超越

## 4. 浏览器抓取技术要点

### Vue SPA 抓取策略（以 flk.npc.gov.cn 为例）

```python
# 错误做法：直接 curl
# 返回 <div id="app"></div> + 静态资源

# 正确做法：浏览器 console 提取
browser_navigate("https://flk.npc.gov.cn/")
browser_type(ref="搜索框", text="台湾同胞投资保护")
browser_click(ref="搜索按钮")
browser_console(expression='document.body.innerText')
# 或更精准：Array.from(document.querySelectorAll('*')).filter(...)
```

### 提取"命中展示"片段的关键 query
```javascript
// 找法律名对应元素
Array.from(document.querySelectorAll('*'))
  .filter(el => el.textContent && el.textContent.includes('中华人民共和国台湾同胞投资保护法'))
  .slice(0, 30)
  .map(el => el.tagName + '|' + (el.getAttribute('data-id') || el.getAttribute('onclick') || ''))
```

### 搜索引擎 CAPTCHA 应对
- Bing 频繁弹"最后一步"——10 次有 6-7 次
- 搜狗反爬更严——直接 antispider 拦截
- **最优策略**：直接访问权威机构首页，查看"最新发布"列表

## 5. 与 26条/31条页面对齐的格式要点

参考范例文件结构：
```
1. 抬头（正式名/通过日期/修正/生效版本/篇幅/配套）
2. 出台背景与立法定位
3. 核心规定（条款摘要）— 表格化
4. 执行层面问题标注 ⚠️ — 5 类
5. 配套法规体系 — 行政法规/政策文件/地方条例
6. 典型案例/新闻 — 1-2 条近期
7. 与相关政策的关系 — 流程图
8. 相关政策链接 — Obsidian 双向链接
9. 信息稿选题角度提示 — 7 条
10. 知识库建设记录 — 表格
```

**避免**：
- 直接抄原文（公开可得，浪费篇幅）
- 没有问题标注（这是本知识库的核心价值）
- 案例无 URL（不可验证）
- 链接不全（破坏双向链接网络）
