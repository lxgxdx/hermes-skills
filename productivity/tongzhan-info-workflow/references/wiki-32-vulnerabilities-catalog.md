## 一、扫描方法（可重复执行）

```python
import os, re

# 扫描 16 个政策文件的"执行层面问题标注"
policies_dir = "/home/lxgxdx/wiki/entities/"
results = {}

for f in sorted(os.listdir(policies_dir)):
    if not f.startswith("policy-") or not f.endswith(".md"):
        continue
    with open(policies_dir + f, encoding="utf-8") as fp:
        content = fp.read()
    # 抓所有 "**xx漏洞** — xx" 格式的小标题
    matches = re.findall(r'^\d+\.\s+\*\*([^*]+)\*\*\s*—\s*([^\n]+)', content, re.MULTILINE)
    if matches:
        results[f] = matches

# 输出每个文件的漏洞点
for f, mlist in results.items():
    print(f"\n【{f}】({len(mlist)}个标注点)")
    for title, desc in mlist:
        print(f"  • {title.strip()} — {desc.strip()[:80]}")
```

> ⚠️ 当 wiki 政策库新增/删除文件时，需重跑此脚本更新本目录。
