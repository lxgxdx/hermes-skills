### 补丁 1：§二B-1 步骤 1 扫描脚本升级为双正则（6/12 验证必做）

**当前**（6/08升级版）：只匹配 `**xx漏洞** — xx` 内联格式

**建议升级**（6/12验证）：

```python
import os, re

policy_dir = "/home/lxgxdx/wiki/entities/"
all_files = sorted([f for f in os.listdir(policy_dir) if f.startswith("policy-") and f.endswith(".md")])

for fname in all_files:
    fpath = os.path.join(policy_dir, fname)
    with open(fpath, encoding="utf-8") as f:
        content = f.read()
    
    # 格式 A：内联标注 **xx漏洞** — xx
    matches_a = re.findall(r'\*\*([^*]+?漏洞)\*\*\s*[—\-]\s*([^\n]+)', content)
    # 格式 B：章节标题 ### 2.x 标题
    matches_b = re.findall(r'###\s*\d+\.\d+\s+([^\n]+)\s*⚠️?', content)
    
    total = len(matches_a) + len(matches_b)
    if total > 0:
        print(f"{fname}: {len(matches_a)} (格式A) + {len(matches_b)} (格式B) = {total}")
```
