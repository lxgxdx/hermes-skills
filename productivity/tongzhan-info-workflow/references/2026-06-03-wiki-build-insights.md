### 发现3：从列表页提取新闻 URL 的高效模式（重要技巧）

**技巧**（适用于所有"权威网站首页要闻列表"场景）：

```javascript
// 在浏览器 console 跑：
Array.from(document.querySelectorAll('a'))
  .filter(a => a.textContent.includes('关键词'))
  .map(a => a.href)
  .join('\n')
```

**适用场景**：
- 国台办"政务要闻"页 `https://www.gwytb.gov.cn/xwdt/zwyw/` 找部际协调机制会议
- 国家民委"民委要闻"找民族工作新闻
- 国家宗教局"要闻"找宗教工作新闻
- 任何"列表页 → 详情页"导航结构的网站

**优势**：相比按索引取，filter 模式更精准、不依赖 ref ID、不需要数清楚第几个 link。

### 发现4：国台办"政务要闻"列表页 URL 规律

**列表页**：`https://www.gwytb.gov.cn/xwdt/zwyw/`（按日期倒序，首页显示最近 50 条 + 翻页）

**详情页 URL 模式**：
- `https://www.gwytb.gov.cn/xwdt/zwyw/YYYYMM/tYYYYMMDD_NNNNNNNN.htm`
- 例如 2026-05-08 部省际会议：`t20260508_12764609.htm`
- 流水号为 8 位数字，看起来是发布序号

**时序识别技巧**：
- 进入 `xwdt/zwyw/` 后用 `full=true` snapshot 拿完整日期列表（每条新闻标题前都有 `[ YYYY-MM-DD ]` 格式日期）
- 优先选"近 1 个月内"的

### 发现5：26条与31条同源（部际协调机制）的制度演进关系

**关键发现**（写入 Wiki 政策页）：
- 2018 "31条" → 20+ 部门联合发文，无明确协调机制
- 2019 "26条" → 仍是多部门联合发文，协调机制仍未制度化
- 2024-12 → 中央台办 + 国家发改委 + 48 部委建立"促进两岸经济文化交流合作部际协调机制"（首次明确）
- 2025-05 → 第二次部际协调机制会议（福州）
- 2026-05 → 第三次部际协调机制会议（北京，"部省际"提法）

**制度分析价值**：从 31 条到 26 条用了 1 年，从 26 条到部际协调机制用了 5 年——**制度回应速度慢**。这本身就是"协调成本高"的具体表现。

### 发现6：Wiki 政策页"执行案例"章节的最低质量门槛

**今日案例**（双案例）：
1. **2024-12-03 新华社**（略超 3 月窗口，但部际协调机制首次提出，最具制度分析价值）
2. **2026-05-08 新华社**（在窗口内，"部省际"会议最新动态）

**选案例标准**（已验证）：
- ✅ 必须是新华社、人民日报、央广网等中央级媒体通稿
- ✅ 必须有具体机制名称（部际协调机制）、具体部门数（48 部委）、具体时间
- ✅ 必须能从制度分析角度切入（不是单纯新闻）
- ⚠️ 案例日期可适度超出"近3月"窗口，但必须有制度价值

**避免**：
- ❌ 地方电视台报道（无全国性）
- ❌ 评论员文章（主观性强）
- ❌ 自媒体二次转载

## 三、本次踩坑与解决

### 踩坑1：直接搜索 `cn.bing.com` 找"26条"相关新闻几乎全部失败

**现象**：Bing 把 "26" 识别为数字常量（数学数字 26 的百度百科、numbermatics.com 等），而不是"26条"政策。

**根因**：Bing 中文版对纯数字查询做"自然数"实体识别优先于政策名称。

**解决**：
- 不依赖 Bing 搜索，直接访问国台办"26条"专题和"政务要闻"列表页
- 用 `browser_console filter` 提取相关链接

### 踩坑2：cn.bing 的"26条 + 落地 + 问题"搜索返回无关内容

**查询**：`"26条" 台胞 同等待遇 落地 问题 2026`
**实际返回**：全部为"26（自然数）_百度百科"等无关内容

**解决**：直接访问 gwytb.gov.cn，绕过 Bing。
