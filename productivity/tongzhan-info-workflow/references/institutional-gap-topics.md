# 制度漏洞类选题发现方法论

> 来源：2026-05-29 飞书会话，用户亲自指导的思路梳理

## 核心理念

问题类信息稿的本质 = **某个制度/机制/文件有缺陷 → 导致实际工作有梗阻**

选题不局限于热点新闻，而是找**制度本身的不完善**。

## 五大切入角度

### 1. 职责边界模糊
- 两个部门职责有交叉地带，实际工作谁都不管
- 例：港澳台侨胞的某些帮扶工作，统战部门和侨联、民政之间边界不清

### 2. 制度空白
- 某类人群/事项没有对应的管理办法，处于"三不管"状态
- 例：网络主播/外卖骑手等新社会阶层群体的统战工作有没有制度安排？

### 3. 文件规定与实际操作脱节
- 文件写了但执行不了，或执行起来走了样
- 例：某些商会规范化建设，文件要求"每年至少召开X次会员大会"，但实际上……

### 4. 配套细则缺失
- 上层文件有原则性规定，但**没有落地细则**，基层不知道怎么操作
- 例：《宗教事务条例》规定了某些要求，但县级层面没有配套操作规程

### 5. 监督机制不完善
- 制度有要求，但缺乏检查、考核、问责机制

## 发现路径

1. **先读 Wiki 政策文件库**（`~/wiki/entities/policy-*.md`）
2. 重点读"执行层面问题标注 ⚠️"章节
3. 对已知的漏洞方向搜索最新执行案例：`site:gov.cn`
4. 对比外地执行情况，看本地是否有差距

## 2026-06-01 新发现：民族团结进步促进法制度漏洞角度

> 来源：人民日报2026年4月14日全文解读 + 中国人大网原始文件

**制度层面可深挖的方向**：

1. **铸牢中华民族共同体意识"为主线"但缺乏量化标准**
   - 法条表述为"主线"，但如何衡量"铸牢"程度？基层如何考核？
   - → 切入点：民族工作成效如何量化评估？

2. **民族团结进步创建的"表彰激励"机制缺失**
   - 法律明确了表彰奖励制度，但地方配套奖励资金来源无规定
   - → 切入点：民族团结进步示范单位创建的激励机制问题

3. **民族地区"共同富裕"政策缺配套细则**
   - 法律要求"推动民族地区共同富裕"，但无具体产业扶持标准
   - → 切入点：少数民族发展资金分配机制问题（已发现：五部门联合设立专项，但基层执行中是否存在撒胡椒面问题？）

4. **民族领域统计数据的监督机制不完善**
   - 国家统计局督察组进驻国家民委（2026年5月18日），说明统计数字质量问题已引起高层关注
   - → 切入点：民族地区统计数据"水分"问题的制度成因
