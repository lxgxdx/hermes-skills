## 一、制度漏洞分类法（2026-06-03 升级为六分法）

> ⚠️ **2026-06-03 更新**：基于 6/02（教职人员跨团体）和 6/03（民族团结展板/党外配而不用/三级网络）实战，识别出第 5 类"跨主体信息不共享"和第 6 类"考核机制软约束"，**从四分法升级为六分法**。

### 1. 职责边界模糊
**定义**：两个或以上部门对同一事项都有职责，但实际运行中谁都管得少、谁都不主责。
**典型表述**：文件写"由XX部门牵头、XX部门配合"，但无具体分工和协调机制。
**发现问题信号**：
- 文件中出现"会同"、"协商"、"配合"等无约束力词汇
- 某项工作涉及多个部门但无牵头单位
- 跨部门事项经常需要"领导协调"才能推动

### 2. 配套细则缺失
**定义**：上层文件有原则性规定，但县级层面没有配套的操作规程，基层不知道怎么执行。
**典型表述**：文件写"应当"、"不得"、"原则上"，但无具体操作标准。
**发现问题信号**：
- 文件有禁止性规定但无罚则
- 文件要求"建立XX机制"但无机制运作的流程设计
- 政策出台后基层反映"不知道怎么做"

### 3. 监督机制不完善
**定义**：制度规定了要求，但无对应的监督主体、监督方式、追责条款，形同虚设。
**典型表述**：文件写了"应当公开"、"应当报告"，但无公开渠道和未公开的处置措施。
**发现问题信号**：
- 制度运行多年但无任何公开的执法/处罚记录
- 监督检查的频率、方式、责任人均不明确
- 出了问题找不到责任主体

### 4. 制度空白
**定义**：某类人群、事项、领域处于"三不管"状态，没有对应的管理制度。
**发现问题信号**：
- 新兴群体/业态出现后长期无统战工作跟进（如：网络主播、外卖骑手、网约车司机）
- 跨领域事项在各部门职责中均未明确提及
- 某类人群想办事找不到受理部门

### 5. 跨主体信息不共享导致违规成本"归零"（2026-06-02 实战新增）

**核心识别信号**：
- 制度本身存在（既不是空白，也不缺细则）
- 多个平等主体之间的资格/资质/处罚信息不互通
- 同一对象被一方除名/处罚后，可在另一方"洗白"重新获得资格
- 违规成本实质上归零

**典型发现位置**：
- Wiki 政策库：`policy-religious-personnel.md` 第 3.3 节"宗教团体'自我管理'监督弱"中"宗教团体之间信息不共享"标注
- 2026-06-02 cron 选题 3 即基于此漏洞生成

**与既有 4 类的关键区别**：
- 不属于"制度空白"——制度有资格认定、备案、处分规定
- 不属于"监督机制不完善"——处分机制运行正常
- 不属于"配套细则缺失"——细则齐全
- 核心问题在**信息共享的横向打通**——制度纵向是完善的，横向是断裂的

### 6. 考核机制软约束（2026-06-03 实战新增候选）

**核心识别信号**：
- 制度本身有考核要求（如"纳入年度考核""应当配备"）
- 考核指标设计偏向"硬指标"（组织保障、宣传教育）而忽略"软指标"（群众获得感、实职分工）
- 考核权重过低或无量化标准，使"做与不做、做多做少"无实质差异
- 制度运行多年但"形式化"现象普遍

**典型发现位置**：
- Wiki 政策库：`policy-minzu-tuanjie.md` 2.2 节"最大问题：形式化"中"展板代替实效"标注
- Wiki 政策库：`policy-shandong-tongzhan.md` 3.1 节"纳入年度考核但考核权重无规定"标注
- Wiki 政策库：`policy-tongzhan-work-regulation.md` 3.5 节"基层宗教工作三级网络落地难"标注
- 2026-06-03 cron 选题 3/4/5 即基于此类漏洞

**与既有 5 类的关键区别**：
- 不属于"职责边界模糊"——职责已明
- 不属于"配套细则缺失"——细则可考
- 不属于"监督机制不完善"——有考核
- 核心问题在**考核机制设计本身**——指标偏离目标、权重过低，使考核沦为"软约束"

def read_docx_text(fpath):

            text = re.sub(r'\s+', ' ', text).strip()

## 三、问题类信息稿 vs 制度漏洞信息稿的区别

| 维度 | 问题类（热点事件） | 制度漏洞类 |
|------|-----------------|-----------|
| 核心 | "发生了什么坏事" | "制度哪里有毛病" |
| 切入点 | 事件/人物/时间 | 文件/条款/机制 |
| 回答的问题 | 现象是什么、谁受害、为什么 | 哪个环节卡住了、为什么卡住、如何改 |
| 数据来源 | 事件本身的数据 | 制度运行中的普遍性表现 |
| 写作难度 | 较易（事件清晰） | 较难（需要制度分析能力） |
| 稳定性 | 低（热点过了就无效） | 高（制度漏洞长期存在） |

## 四、选题推荐原则

1. **优先选配套细则缺失**：有文件依据但基层不知道怎么执行，角度清晰
2. **慎选制度空白**：空白类需要大量调查才能写充实，易空洞
3. **监督类要谨慎**：无数据支撑时容易写成"呼吁型"文章
4. **职责边界类优先选多部门交集点**：台胞同等待遇涉及部门最多，最容易出选题
5. **第 5 类（跨主体信息不共享）优先**：制度漏洞新颖，违反者"换马甲洗白"的乱象可读性高
6. **第 6 类（考核机制软约束）需真实案例支撑**：避免写成"呼吁型"——必须有"展板代替实效""一人多岗"等具体表现

## 五、维度互补排重判断法（2026-06-03 实战新增）

> **核心问题**：当两个选题看起来指向同一领域（如都讲"基层宗教力量薄弱"）时，如何判断是"重复"还是"互补"？

**判断标准**（2026-06-03 验证有效）：

| 情况 | 重复 | 互补 |
|------|------|------|
| **空间维度** | 都讲"县一级" | 一个讲"县一级" + 一个讲"县-乡-村三级联动" |
| **机制维度** | 都讲"准入机制" | 一个讲"准入" + 一个讲"管理" |
| **对象维度** | 都讲"宗教教职人员" | 一个讲"宗教教职人员" + 一个讲"民间信仰活动场所" |
| **时间维度** | 都讲"执行难" | 一个讲"准入阶段" + 一个讲"退出阶段" |

**实战案例**（2026-06-03 cron）：
- 6/01 选题"基层宗教部门小马拉大车"（县一级人员不足 1-2 人，**空间维度：县**）
- 6/03 选题"基层宗教工作三级网络有名无实"（县-乡-村三级联动失效，**空间维度：三级**）
- **判断**：角度互补，**不构成重复**——6/01 聚焦"县"环节的"人少事多"，6/03 聚焦"县-乡-村"三级的"联动失效"，且 6/03 还关联"任务重"标准缺失的根源
- **排重备注必须明确写出维度差异**，避免用户复盘时误判为重复

**操作建议**：
1. 排重前对每个候选选题提取"维度标签"（空间/机制/对象/时间/参与主体）
2. 与已写选题逐一对比维度标签
3. 维度完全相同 → 重复
4. 至少 1 个维度不同 + 其他维度有关联 → 互补（可写但需明确差异）
5. 所有维度都不同 → 新角度（首选）
