# 飞书妙记文字稿 → Word 公文格式会议记录

> **2026-06-01 验证：飞书妙记是政府会议录音转写的最优方案**
> 飞书妙记输出的 Word 文字稿可直接使用，无需本地 Whisper 转录。
> MiniMax API 也不提供 STT 端点（`/v1/audio/transcriptions` 返回 404）。

---

## 标准工作流程

```
飞书妙记文字稿(.docx) + 会议议题表(.doc/.docx)
    → 读取文字稿 → 确认发言人身份 → 按议题整理 → Word公文格式输出
```

### 步骤一：扫描目录，找到文件

```bash
ls -lh "/mnt/nfs/2026年统战工作/1.办公室/9.部务会/5.27/"
```

文件通常包含：
- `文字记录：REC009x 2026年x月x日.docx` — 飞书妙记转写稿（说话人+时间戳格式）
- `会议议题.doc` / `会议议题.docx` — 议题表（主持/领学/汇报人信息）
- `REC009x.WAV` — 原始录音（可跳过）

### 步骤二：读取飞书妙记文字稿

```python
# 飞书妙记格式：段落文本含"说话人 X HH:MM:SS"时间戳
from docx import Document

doc = Document('文字记录：REC0091 2026年6月1日.docx')
for para in doc.paragraphs:
    if para.text.strip():
        print(para.text)
```

### 步骤三：读取会议议题表（.doc 旧格式需转换）

```bash
# .doc 文件（旧版Office 97-2003格式）python-docx无法直接读取
file "会议议题.doc"
# 输出含 "Composite Document File V2 Document" 即为旧格式

# 转换方法
libreoffice --headless --convert-to txt "会议议题.doc" --outdir /tmp/
# 然后读取生成的 /tmp/会议议题.txt
```

### 步骤四：识别发言人身份

飞书妙记的"说话人 X"需要对照议题表还原真实身份：

| 说话人 | 通常身份 |
|--------|---------|
| 说话人 1 | 主持人（张道伟，主持会议） |
| 说话人 2 | 汇报人/分管领导（徐军光） |
| 说话人 3 | 领学/汇报人（苑芳江） |
| 说话人 4 | 列席人员/其他（朱芳、秀美、老谢、俊芳） |
| 说话人 5 | 分管领导（徐军光/秀美） |

**确认方法**：对照议题表中的"领学/汇报/列席"标注，结合发言内容判断。

### 步骤五：按议题结构化整理

政府会议记录的整理原则（非逐字稿）：

**领学类议题**（议题一、二）：
```
一、第一议题
***领学：XXX***
一句话概括学习内容 + 会议要求（无需还原领学对话细节）
```

**汇报类议题**（议题三、四）：
```
三、审议《XXX办法》
***汇报：XXX（XXX列席）***
要点归纳：汇报人说了什么 + 讨论意见 + 表决结果
保留具体修改意见（如朱芳对"上级党代会代表"的修改建议）
```

**分管汇报类议题**（议题五）：
```
五、各分管领导汇报近期工作情况

***XXX同志（工作领域）：***
- 工作项1；
- 工作项2；
（以分点列表呈现，附分管领导或主要领导点评）
```

**讲话类议题**（议题六）：
```
六、XXX同志讲话
- 要点1；
- 要点2；
（归纳式，不是逐字记录）
```

### 步骤六：生成 Word 公文格式

**字体规范**：
- 页边距：上3.5cm、下3.2cm、左右2.7cm
- 标题：方正小标宋简体 22pt，居中
- 一级标题：黑体三号（16pt）
- 正文：仿宋_GB2312 三号（16pt），首行缩进2字符
- 行距：固定值 28 磅，两端对齐

**文件落盘后必须验证**：
```python
import os
size = os.path.getsize(out_path)
assert size > 0, f"❌ 文件大小为0：{out_path}"
print(f"✅ 已保存，大小：{size} 字节")
```

## 已知局限与备选方案

| 方案 | 适用场景 | 局限 |
|------|---------|------|
| **飞书妙记**（本次验证）✅ | 有网络、能上传音频 | 需手动上传，生成Word文字稿 |
| 本地 Whisper（faster-whisper medium int8） | 保密/离线场景 | CPU慢(2-4h)，识别率低（ADPCM录音） |
| 讯飞听见 | 正式政府会议 | 付费，有API |
| MiniMax API | — | ❌ 无 STT 端点（已确认404） |
