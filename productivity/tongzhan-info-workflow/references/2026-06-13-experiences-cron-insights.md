### 踩坑1：6/12 自查问题清单 .docx 实际是表格结构，python-docx 段落读取返回空

**现象**：6/13 cron 第一次读取 `/mnt/nfs/2026年统战工作/1.办公室/47.落实统战工作责任制自查/五莲县自查问题清单.docx` 时：
- `doc.paragraphs` 全部为空
- 实际内容在 `doc.tables` 中（4 方面 7 条问题 + 7 条整改措施）

**解决**：
```python
import docx
doc = docx.Document("/mnt/nfs/.../五莲县自查问题清单.docx")
for i, t in enumerate(doc.tables):
    for r, row in enumerate(t.rows):
        cells_text = [c.text.strip() for c in row.cells]
        if r > 0:
            print(f"R{r}: {cells_text}")
```

**6/13 实际产出**：完整 4 方面 7 条问题 + 7 条整改措施全部读取

**对 SKILL.md 的影响**：
- 在 §7.2"读取 docx 的标准方法"中**新增"doc.tables 读取"分支**——当 doc.paragraphs 为空时，切换到 doc.tables

### 踩坑2：6/12 半年工作总结 4 份 .doc 文件需用 libreoffice 转换

**现象**：6/13 cron 用 python-docx 读取 `民族工作上半年总结及下半年工作打算.doc` 时报 `PackageNotFoundError`
- 该文件是 .doc 后缀（实际内容是旧版 .doc 二进制格式）
- python-docx **不能读取** 旧版 .doc 格式

**解决**：
```bash
# 用 libreoffice 转换为 txt
libreoffice --headless --convert-to txt --outdir /tmp "/mnt/nfs/.../民族工作上半年总结及下半年工作打算.doc"
# 直接 cat 读取
cat "/tmp/民族工作上半年总结及下半年工作打算.txt" | head -80
```

**6/13 实际产出**：4 份 .doc 文件（民族+宗教+台港澳+党建）全部成功读取

**对 SKILL.md 的影响**：
- 在 §7.2"读取 docx 的标准方法"中**新增".doc 旧版文件读取法"**——libreoffice 转换 + cat 文本
- 在"关键本地文件清单"中**标注 6/12 半年工作总结 4 份 .doc 文件需用 libreoffice 转换**
