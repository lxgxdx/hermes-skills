# 统战部 Excel 台账标准化流程

## ⚡ QuickRef

**台账主文件：** `TZB/2026年统战工作/6.巡查部机关/6.备份/五莲县统一战线重要会议目录.xlsx`

**年度结构：** 每个年份一个 Sheet，列包含：序号、日期、年份、月份、旬（ 上旬/中旬/下旬）、会议名称、主办单位、备注

**格式标准：**
- 标题行：宋体 14pt 加粗，居中，浅蓝底色
- 内容：宋体 12pt，左对齐，自动换行，行高 30
- 有序号的内容：居左
- 日期格式：`YYYY.MM.DD`
- 年份 Sheet：`2020`、`2021`...`2026`

## 任务类型

### 类型A：更新会议目录（最常见）

当用户提供补充材料时：
1. 从材料中读取：**会议名称、日期、主办单位**
2. 判断年份 → 确定落在哪个 Sheet
3. 判断旬（上旬=1-10日，中旬=11-20日，下旬=21-31日）
4. 查找该年份最大序号 → 新序号 = 最大+1
5. 在对应位置插入新行

```python
# 序号格式：纯数字，如 1, 2, 3...
# 涉密文件：序号跳过，不用添加
# 作废序号：保留原序号，后续序号顺延
```

**注意：** 找不到日期时，从会议内容/会议通知中读取。

### 类型B：新增年份 Sheet

1. 复制上一年份 Sheet 作为模板
2. 修改 Sheet 名称为新年份（如 `2026`）
3. 清空内容行（保留标题行）
4. 序号从 1 开始

### 类型C：文件重命名（按序号前缀）

用户修改了 Excel 台账中的序号后，需要将对应文件按新序号重命名。

**逻辑：**
```
Excel 中「1.《文件A》」→ 文件系统「1.《文件A》」
Excel 中「2.《文件B》」→ 文件系统「2.《文件B》」
```
涉密文件：保持原名，不加序号
作废序号：文件不动（没有对应的新序号）

**注意：** 日期与文件夹名不一致时，**以文件夹名为准**。

### 类型D：Excel 格式排版

用户要求「方便阅读」时，应用以下标准：

| 元素 | 标准 |
|------|------|
| 标题行 | 宋体 14pt 加粗，#D6E4F0 浅蓝底色，居中 |
| 内容行 | 宋体 12pt，左对齐，自动换行 |
| 行高 | 最小 30（自动） |
| 列宽 | A列(序号) 6，B列(日期) 12，C列(年份) 6，D列(月份) 6，E列(旬) 8， F列(会议名称) 40，G列(主办单位) 16，H列(备注) 20 |
| 边框 | 所有单元格四周细线边框 |
| 对齐 | 序号/年份/月份/旬居中，日期居左，会议名称居左，备注居左 |

## 文件夹命名规范

- 格式：`年份.月份.日期_会议简称`
- 示例：`2022.01.10_党外人士座谈会`、`2026.03.15_新联会`
- 补充材料文件夹：`补充材料/`

**当日期与文件夹名不一致时：** 以文件夹名为准，日期用于 Excel 台账。
