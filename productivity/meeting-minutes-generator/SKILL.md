# 会议记录生成器

## 触发条件

用户说"整理会议记录"、"改一下会议记录"、或提供了飞书妙记/Whisper 转录的部务会录音文字稿文件路径时使用。也包括用户**指出已生成文档某处不对，要求修改**的场景（这是迭代修订流程，不是首次整理）。

## 前置确认（整理前必须询问）

3. **说话人映射**：文字稿中非固定称呼（老谢/俊芳/秀美等）分别对应哪位成员

## 文件识别与读取

**🆕 M3 多模态优先（2026-06 确立）：** 当前模型有原生视觉能力。处理扫描件/图片型文档时优先 vision_analyze，libreoffice 转 txt 只作为兜底。

```python
# 扫描件/图片型文档 — M3 优先（不要走 OCR）
from hermes_tools import vision_analyze
import subprocess, os

# 把 docx 首页转图片（M3 不能直接读 PDF/docx，需转图）
def docx_to_image(docx_path, page=1):
    """把 docx 的第1页转成 PNG 图片"""
    import subprocess
    pdf_path = '/tmp/_tmp.pdf'
    subprocess.run(['libreoffice', '--headless', '--convert-to', 'pdf',
                    '--outdir', '/tmp', docx_path],
                   timeout=30, capture_output=True)
    base = os.path.splitext(os.path.basename(docx_path))[0]
    found_pdf = os.path.join('/tmp', base + '.pdf')
    if os.path.exists(found_pdf):
        img_prefix = '/tmp/doc_page'
        subprocess.run(['pdftoppm', '-f', str(page), '-l', str(page),
                        '-png', '-r', '200', found_pdf, img_prefix],
                       timeout=30)
        return f'{img_prefix}-{page:03d}.png'
    return None

# 使用方式
img = docx_to_image('文字记录：REC0091.docx')
if img:
    vision_analyze(image_url=img,
                   question="这份文字稿里有哪些发言人和议题？提取说话人姓名和发言内容。")
```

## 格式规范

### 标题层级（按模板）

| 层级 | 格式 | 字体 | 加粗 | 字号 |
|------|------|------|------|------|
| 大标题 | 文件名 | 方正小标宋简体 | 否 | 22pt，居中 |
| 副标题 | （2026年第N次部务会） | 仿宋 | 否 | 16pt，居中 |
| 议题标题 | 一、学习…… | 黑体 | 否 | 16pt |
| 分管汇报小标题 | （一）XXX同志汇报…… | 楷体 | 否 | 16pt |
| 正文 | 会议内容段落 | 仿宋 | 否 | 16pt，首行缩进 |
| 编号条目 | 1. 内容 | 仿宋 | 否 | 16pt，首行缩进 |

### 排版规范

- **行间距**：固定值 28 磅（所有段落）
- **页边距**：上下左右各 2.54cm
- **首行缩进**：正文段落首行缩进 0.74cm（2字符）；标题不缩进
- **对齐**：正文两端对齐（JUSTIFY）；大标题/副标题居中

### 格式禁忌

- 正文不使用斜体、不使用 `*` 包围
- 不嵌套【（一）领学】【（二）研究贯彻意见】等层级

## 议题处理规则

### 领学类议题（一、二）
- **领学句**：一句概括"X 同志领学了 Y 讲话/文章"的事实记录
  - **领学句必须穷举议题标题中的所有领学对象**（如议题标题是"特朗普、普京会谈 + 政治局学习"，领学句不能漏普京）
- **会议指出/会议要求/会议强调**：必须是**部务会研究后形成的贯彻落实意见**（一要...二要...），**不是对原文内容的概括复述**
  - ❌ 错误：把原文材料里的论断改写成"会议指出 XXX"（这是把原文当成了会议意见）
  - ✅ 正确：基于原文精神，结合县统战部实际工作，写"会议要求，一要...二要..."
  - 如果录音里没有具体研究意见，可由 AI 自行撰写 1-2 句符合公文规范的贯彻落实要求
- **不逐句记录领学过程**（不抄原文段落）

### 审议类议题（三：三重一大）
- 汇报人说明 → 分管领导逐一发言（原话，末尾表态）
- 表决结果：经审议，原则通过，修改完善后印发执行
- 格式：`姓名：同意` 或 `姓名：同意，+具体意见`

### 研究类议题（四：信息宣传）
- 情况通报（一句概括）+ 领导要求（分条：一要、二要……）
- 不逐句记录讨论过程

### 汇报类议题（五）
- 按发言人分块，每位分管领导独立小标题
- 事项用分号分隔，重要成果单独成句
- 领导对汇报的点评跟在汇报人之后

### 讲话类议题（六：主要领导讲话）
- **首选基于录音原文整理**（用户在 2026-06-02 明确要求："尽量采用原来的录音文字进行整理"）
  - **检索方法**：用 `grep -n "张道伟\|张部长\|道伟同志" "/tmp/REC00XX.txt"` 定位讲话时段；同时关注 "说话人 N 00:5X:XX" 的时间戳（一般主讲话人在议题结尾 + 议题之间过渡段发言）
  - 提取每段讲话的核心要点（多在议题结尾 + 议题之间的过渡段）
  - 一条要点对应讲话里一个独立主题（吃透要求 / 成立专班 / 借力发力 / 挖掘亮点 等）
- **没有录音的部分**才"根据本次部务会内容适当发挥"：
  - 总收尾句（"六要抓好会议精神的传达落实"）：基于议题一到五的统揽，写责任分工 + 重点任务落地
  - 切忌凭空编造通用党政套话（"深入学习/突出重点/强化自身建设/抓好工作落实/守好安全底线"这种模板 v5 全部被用户打回重做）
- 格式：归纳为 3-6 条要点（一要、二要……），不逐句转写
- 讲话类议题中引用具体工作（如"民营企业进边疆""寻美五莲""大青山太极拳大赛"）时，**这些信息必须来自录音或本次议题五各分管领导汇报内容**，不得生造
- **用户一次说多个问题就一并改**：议题一 + 议题二 + 议题六可以一次性 patch 进同一个 v5 脚本，不要分多次"等用户审阅"——除非用户明确说"先看这个再看下一个"

### ❌ 讲话内容套话化（v5 版踩坑，2026-06-02 用户纠正）
原因：议题六张部长讲话 v5 写的是通用党政模板（"一要深入学习/二要突出重点打造亮点/三要强化自身建设/四要抓好工作落实/五要守好安全底线"），与本次部务会的实际内容毫无关联
正确：
- 必须**尽量采用录音原文**（搜索 REC00XX 中张部长讲话的时段，整理核心要点）
- 录音没有的内容**根据本次部务会内容适当发挥**（基于议题一到五的具体议题）
- 不可使用"深入学习/突出重点/强化自身建设/抓好工作落实/守好安全底线"这种通用党政模板

### ❌ 贯彻落实意见凭空生成（v5 版踩坑，2026-06-02 用户纠正）
原因：v5 议题一的"二要"写"树牢底线思维、极限思维，扎实做好宗教领域安全、意识形态安全……"——这跟议题一学的"中美俄外交+防灾减灾"完全没关系，是套话模板
正确：
- "会议要求"里的**每一条都必须从本次学习内容本身推导**（议题一学了外交 + 防灾减灾 → 贯彻落实意见也要从这两个方向写）
- 严禁把"树牢底线思维/守好安全底线/意识形态安全"等通用党政安全话术硬塞进与学习内容无关的议题

### ❌ 引用中文标点符号「」（2026-06-02 用户纠正）
原因：用户原话"这种符号在手写的部务会会议记录当中一般是不存在的"——「」在党政公文/手写记录里几乎不用
正确：
- 公文里**只使用中文双引号 `"为民务实"`**（注意：在 Python 源码里字符串外层用双引号时，内部中文双引号必须用 `\"...\"` 反斜杠转义；否则 SyntaxError）
- 同样不推荐使用：单引号 `'...'`（英文）、`『...』`、`【...】` 等非公文标点

## 工作流程

1. **读议题表**：libreoffice 转 txt，确认议题顺序和列席人员
2. **读文字稿**：两个 REC 文件通读一遍，标记说话人编号对应的发言内容
3. **推断说话人映射**：对照①议题表领学/汇报人 ②文字稿中说话内容，交叉验证
4. **询问用户确认**：请假人员、临时列席人员、说话人映射是否正确
5. **生成文档**：按本 skill 格式规范写 Python 脚本生成 Word
6. **保存**：`/mnt/nfs/2026年统战工作/1.办公室/9.部务会/日期/会议记录_YYYY年第N次部务会.docx`

## 常见错误（踩坑记录）

### ❌ 议题内容搞反（v2/v3版）
原因：看到议题名"民族工作"就假设是李兵，没对照文字稿核实
正确：议题一/二的内容完全由文字稿决定，议题表只决定顺序

### ❌ 说话人映射套用上次
每次会议说话人编号对应的人名不同，必须通过领学人说了什么+议题表领学人是谁来交叉验证

### ❌ 嵌套层级过多
模板格式不用【（一）领学】【（二）研究贯彻意见】，议题直接一、二、三标出

### ❌ 人员带职务列示
模板格式只写姓名，不用职务，不标注"不发言，负责记录"

### ❌ 把原文材料当"会议指出"（v5 版踩坑，2026-06-02 用户纠正）
原因：v5 把议题一参考资料（特朗普会谈/防灾减灾）的大段原文概括改写为"会议指出..."、"会议强调..."，这是把原文当成了会议意见
正确：
- "会议指出/强调/要求"是**部务会研究后形成的贯彻落实意见**，不是对原文的复述
- 领学句写一句事实（"X 同志领学了 Y"）即可
- 之后接"会议要求，一要...二要..." —— 基于原文精神，结合县统战部实际
- 录音里没具体研究意见时，AI 自行撰写 1-2 句符合公文规范的贯彻落实要求

### ❌ 贯彻落实意见凭空套话（议题一/六，v5 修正后又被纠正，2026-06-02）
即使改成"会议要求，一要...二要..."格式，每一条也必须**从本次学习/讨论内容本身推导**。典型反例：
- 议题一学了"中美俄外交+防灾减灾"，"会议要求"却写"树牢底线思维、极限思维，扎实做好宗教领域安全、意识形态安全……"——这些词与议题一的学习内容完全无关，是从其他议题硬塞过来的
- 议题六张部长讲话写成"深入学习/突出重点/强化自身建设/抓好工作落实/守好安全底线"通用党政模板——脱离本次部务会的具体内容
正确方法：
- **议题一/二贯彻落实意见**：基于本次学习内容（外交 / 防灾减灾 / 正确政绩观）推导一两条落到统战工作上的要求
- **议题六讲话**：必须用录音原文整理要点；录音没有的部分**根据本次部务会内容**（议题一到五的具体议题）适当发挥
- 检验：每条"会议要求"或讲话要点，能否在录音/议题内容里找到对应依据？找不到就是凭空套话

### ❌ 领学句漏掉议题标题里的人物/对象（2026-06-02 v5 修正）
原因：议题一标题是"特朗普、普京会谈 + 政治局集体学习"三项内容，v5 领学句只提"特朗普会谈 + 政治局学习"两个，漏了"普京会谈"
正确：领学句必须穷举议题标题中的**所有领学对象**，逐一对应

### ❌ 讲话类议题用"3-5 条要点"通用模板（议题六 v5 踩坑）
原因：v5 议题六写了 5 条通用党政套话（深入学习/突出重点/强化自身建设/抓好工作落实/守好安全底线），与本次部务会内容完全脱节
正确：讲话类议题**首选基于录音原文整理**（见"议题处理规则-讲话类议题"），无录音时才"根据本次部务会内容适当发挥"，不能用通用模板凑数

### ❌ 在 Python 字符串里嵌入中文双引号（v5 源码 SyntaxError，2026-06-02 实测）
原因：v5 写 `info(doc, "...\"为民务实\"...", ...)` 想在正文里用中文双引号，但 `info` 第一个参数是 Python 字符串，源码用 `"..."` 包裹时内部的中文双引号需要 `\"` 转义
踩坑现场：
- ❌ `info(doc, "...树牢"为民务实"导向...", sa=6)` → SyntaxError: invalid syntax
- ✅ `info(doc, "...树牢\"为民务实\"导向...", sa=6)` → 正确（外层双引号 + 内部 `\"` 转义）
- ✅ 改用单引号外层 `info(doc, '...树牢"为民务实"导向...', sa=6)` 也可以
替代：避免嵌套引号时，可改用「」（但用户 2026-06-02 明确说公文里不用「」，所以这个方案已被否定）

FONT_FZXBSJK = "方正小标宋简体"
FONT_HT = "黑体"
FONT_KT = "楷体"
FONT_FS = "仿宋"

def set_font(run, font_name, size, bold=False):
    run.font.name = font_name
    run.font.size = Pt(size)
    run.font.bold = bold
    run._element.rPr.rFonts.set(qn('w:eastAsia'), font_name)

def set_lnSpc(p, val=28):
    pPr = p._element.get_or_add_pPr()
    lSpc = OxmlElement('w:lnSpc')
    lSpcVal = OxmlElement('w:lnSpcVal')
    lSpcVal.set(qn('w:val'), str(val))
    lSpc.append(lSpcVal)
    pPr.append(lSpc)

def info(doc, text, sb=0, sa=3):
    """正文段落 仿宋 首行缩进"""
    p = doc.add_paragraph()
    p.paragraph_format.space_before = Pt(sb)
    p.paragraph_format.space_after = Pt(sa)
    p.paragraph_format.first_line_indent = Cm(0.74)
    run = p.add_run(text)
    set_font(run, FONT_FS, 16)
    set_lnSpc(p)
    return p

def agenda(doc, text):
    """议题标题 黑体"""
    p = doc.add_paragraph()
    p.paragraph_format.space_before = Pt(12)
    p.paragraph_format.space_after = Pt(6)
    run = p.add_run(text)
    set_font(run, FONT_HT, 16, bold=False)
    set_lnSpc(p)
    return p
